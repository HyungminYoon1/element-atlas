# ELEMENT ATLAS · 원소 도감

118개 원소의 주기율표, 실제 표본과 물성 비교, 전자배치·이온·동위원소 문제 풀이. 독립된 정적 GitHub Pages 서비스입니다.

## 실행

Node 22 이상. 런타임/개발 의존성 설치 없이 `npm run dev`를 실행하면 표시된 localhost 주소에서 열 수 있습니다. `npm test`, `npm run check`로 모델과 공개 파일을 검사합니다.

## 기능

- 이름·별칭·기호·원자번호 검색, 분류 및 물성 색 지도, 키보드 탐색, 최대 3개 원소 비교.
- 118개 원소의 전자배치와 PubChem 물성값, CIAAW 표준 원자량의 구간·불확도 표기. 2024 Zr/Gd/Lu 개정 포함.
- 실제 원소 표본 사진 56개. 사진의 표면 상태·동소체·산화막을 구분하고 저작자·원본·재사용 조건을 연결합니다.
- 순수 원소 결정 기록이 있는 원소 89개. 최대 3개 COD 기록의 격자 상수·공간군·기재된 측정 조건·원 논문·CIF를 연결합니다. 셀 외곽 도식은 원자 위치 모델이 아닙니다.
- 네 난이도와 범주별 문제: 기호/위치, 전자배치, 이온 전자 수, 물성 비교, 가상 표본의 동위원소 가중평균·존재비 역산, 산화수, 등전자 이온 반지름, 핵자 수, 전이 금속 이온 전자배치.
- 새 문제마다 암호학적 난수 시드와 새 선택지 순서. 답/풀이/다음 단계 분리, 중복 채점 방지, 오답 원소 집중 복습.
- 학습 기록은 이 브라우저의 독립된 키에만 저장합니다. JSON 저장/불러오기와 명시적 초기화. 공개 랭킹, 계정, 서버, 트래커와 마이크 사용은 없습니다.

## 자료와 라이선스

수집일 2026-10-09. PubChem 주기율표의 수치와 CIAAW 표준 원자량을 사용합니다. 원자 반지름·밀도·상전이의 정의 및 조건은 원문을 확인해야 합니다. 표준 원자량이 없는 원소에서 대표 동위원소 질량을 표준값으로 취급하지 않습니다. 초중원소의 예측 전자배치를 표시합니다. 모든 최신 연구를 포괄하거나 전문 과학자의 검토를 대체하지는 않습니다.

결정 수치는 Crystallography Open Database(CC0 1.0)의 단일 원소 기록이며 각 저자·원 논문을 표시합니다. 기재가 없는 측정 조건은 추정하지 않습니다. 검색 결과는 동일 원소의 서로 다른 상·조건을 포함할 수 있습니다.

사진은 Wikimedia Commons 원본의 CC BY / CC BY-SA / CC0 / Public domain / Free Art License 조건을 유지합니다. 웹 표시용 축소본이며 별도의 이미지 이용 허가를 새로 부여하지 않습니다. 원 저작자, 작품명, 원본 URL, 라이선스 URL은 원소 상세 및 `dist/assets/attributions.json`에서 이미지별로 확인할 수 있습니다. FAL 사진은 [Free Art License 1.3](https://artlibre.org/licence/lal/en/)에 따라 별도로 재사용할 수 있습니다. 사이트 코드와 사진은 구분됩니다.

`tools/import-data.mjs`는 개발 중에만 실행하는 데이터 수집기입니다. CIAAW/PubChem의 표 형식이나 출처·라이선스가 바뀌면 자동 배포하지 말고 검토해야 합니다. `--photos-only` 옵션은 기존 검토된 결정 기록을 유지하며 숫자·사진 출처를 갱신합니다. 실제 사이트에서는 외부 API 요청 없이 같은 출처의 파일만 읽습니다.

## 문서와 검증

`architecture.md`, `requirements.md`, `docs/decisions.md`가 경계와 승인 범위를 정의합니다. `docs/verification.md`에서 모델/브라우저/원격 CI/공개 사이트 결과를 구분합니다. 공유 완료 요약인 `web-lab-progress-v1`은 읽거나 쓰지 않습니다.
