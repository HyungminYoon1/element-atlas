# ELEMENT ATLAS · 원소 도감

118개 원소의 주기율표, 실제 표본과 물성 비교, 전자배치·이온·동위원소 문제 풀이. 독립된 정적 GitHub Pages 서비스입니다.

## 실행

Node 22 이상. 런타임/개발 의존성 설치 없이 `npm run dev`를 실행하면 표시된 localhost 주소에서 열 수 있습니다. `npm test`, `npm run check`로 모델과 공개 파일을 검사합니다.

## 기능

- 첫 화면의 학습 길잡이: 입자 수·양자 상태·전자배치·주기성·차폐·이온화·결합·구조·상태·추론의 10개 단원. 규칙/근거/사례/적용 범위/확인 질문과 관련 원소·문제로 연결합니다.
- 각 단원의 추가 추론 도전 10개: 동위원소와 이온을 함께 계산하고, O/O²⁻ 점유·N/O 이온화 예외·Fe³⁺·결합 에너지·사진 관측 조건을 연결합니다. 첫 선택과 해설은 단원을 오가도 현재 화면에 남고 기기 기록을 늘리지 않습니다.
- 실제 데이터에 기반한 1–30번 원소와 지정 이온의 오비탈 점유 작업대, Cr/Cu 예외와 4s 우선 이온화, 수소 1s의 확률 밀도와 구껍질 확률 비교. 도식은 전자의 궤적이 아닙니다. 개념 확인 상태는 현재 화면 메모리에만 남고 기존 문제 기록·공유 저장은 바꾸지 않습니다.
- 이름·별칭·기호·원자번호 검색, 분류 및 물성 색 지도, 키보드 탐색, 최대 3개 원소 비교.
- 118개 원소의 전자배치와 PubChem 물성값, CIAAW 표준 원자량의 구간·불확도 표기. 2024 Zr/Gd/Lu 개정 포함.
- 97종의 실제 촬영 자료 100장. 표본·도금·현미경 사진 87종과 방전광·방사선 궤적 등 관측 자료 10종을 구분합니다. 액체 헬륨·질소·산소·플루오린, 고체 염소, 고체·액체 아르곤·제논을 포함합니다. 상태별 사진 선택과 자료 유형 필터를 제공합니다.
- 전체 118종의 사진 수록 여부·누락 사유·검토 출처를 확인할 수 있습니다. 퀴륨의 사진 원본 미확보를 표본이 존재하지 않는 것으로 취급하지 않습니다. 순수 표면이 확인되지 않은 자료, 방전광, 피복과 산화층도 별도 설명합니다.
- 순수 원소 결정 기록이 있는 원소 89개. 최대 3개 COD 기록의 격자 상수·공간군·기재된 측정 조건·원 논문·CIF를 연결합니다. 셀 외곽 도식은 원자 위치 모델이 아닙니다.
- 네 난이도와 범주별 문제: 기호/위치, 전자배치, 이온 전자 수, 물성 비교, 가상 표본의 동위원소 가중평균·존재비 역산, 산화수, 등전자 이온 반지름, 핵자 수, 전이 금속 이온 전자배치.
- 새 문제마다 암호학적 난수 시드와 새 선택지 순서. 답/풀이/다음 단계 분리, 중복 채점 방지, 오답 원소 집중 복습.
- 학습 기록은 이 브라우저의 독립된 키에만 저장합니다. JSON 저장/불러오기와 명시적 초기화. 공개 랭킹, 계정, 서버, 트래커와 마이크 사용은 없습니다.

## 자료와 라이선스

수집일 2026-10-09. PubChem 주기율표의 수치와 CIAAW 표준 원자량을 사용합니다. 원자 반지름·밀도·상전이의 정의 및 조건은 원문을 확인해야 합니다. 표준 원자량이 없는 원소에서 대표 동위원소 질량을 표준값으로 취급하지 않습니다. 초중원소의 예측 전자배치를 표시합니다. 모든 최신 연구를 포괄하거나 전문 과학자의 검토를 대체하지는 않습니다.

결정 수치는 Crystallography Open Database(CC0 1.0)의 단일 원소 기록이며 각 저자·원 논문을 표시합니다. 기재가 없는 측정 조건은 추정하지 않습니다. 검색 결과는 동일 원소의 서로 다른 상·조건을 포함할 수 있습니다.

사진은 Wikimedia Commons 원본의 CC BY / CC BY-SA / CC0 / Public domain / Free Art License 조건을 유지합니다. 웹 표시용 축소본이며 별도의 이미지 이용 허가를 새로 부여하지 않습니다. 원 저작자, 작품명, 원본 URL, 라이선스 URL은 원소 상세 및 `dist/assets/attributions.json`에서 이미지별로 확인할 수 있습니다. FAL 사진은 [Free Art License 1.3](https://artlibre.org/licence/lal/en/)에 따라 별도로 재사용할 수 있습니다. 사이트 코드와 사진은 구분됩니다.

`tools/photo-manifest.json`은 모든 118종의 사진 검토 목록입니다. 수록 작품을 개별 지정하여 영문 이름 차이나 대표 사진의 선택에 따라 사진이 빠지지 않게 합니다. 새로운 자료는 사진 속 상태·관찰 방식·원본·재사용 조건을 먼저 검토해 이 목록에 추가합니다.

`npm run import:photos` 또는 `npm run import:data -- --photos-only`는 사진과 사진 검토 기록만 갱신합니다. 기존 수치·전자배치·결정 기록은 그대로 유지되며 PubChem/CIAAW/COD에 요청하지 않습니다. 출처나 재사용 조건을 확인할 수 없는 사진은 새 스냅샷에 자동 반영하지 않고 실행을 실패시킵니다.

`tools/import-data.mjs`는 전체 과학 자료를 갱신할 때만 실행하는 수집기입니다. CIAAW/PubChem의 표 형식이나 출처·라이선스가 바뀌면 자동 배포하지 말고 검토해야 합니다. 실제 사이트에서는 외부 API 요청 없이 같은 출처의 파일만 읽습니다. LANL의 플루토늄 사진에는 별도의 출처 표기 조건과 전체 고지문을 `dist/assets/licenses/LANL-NOTICE.txt`에 유지합니다.

## 문서와 검증

[추론 도전의 개념 출처](docs/learning-provenance.md). 기록 파일을 불러온 뒤 브라우저 저장에 실패하면 화면에만 불러온 상태임을 안내합니다. 새로고침 전에 JSON으로 다시 저장할 수 있습니다.
