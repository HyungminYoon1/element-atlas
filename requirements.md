# Approved scope and acceptance

Approved on 2026-10-09: build a useful, engaging chemistry/periodic-table learning service with diverse questions, high-quality real elemental images, appearance and crystal information, and current authoritative science. One implementing agent sequentially; no subagents.

- All 118 elements: Korean name, symbol, number, group/period and electron configuration; numeric properties where sources supply them. Search/filter/keyboard access, compare up to three, detail/source/image attribution.
- Element explorer with property maps and clear units, actual photos where a licensed pure sample is verified, unknown-photo state where not. Photo may show a specific allotrope or sample surface, not an universal color.
- Learning modes: symbol/name, position, group/period, configuration/electron count, relative properties and inference, oxidation/ion reasoning, isotope weighted mean; diverse parameterized authored questions with four levels, immediate detailed reasoning and wrong-answer practice.
- Deliberate answer/next lifecycle, no duplicate scoring, random order/options between attempts, reproducible internal seeds, no guessed clinical/population ranks.
- Crystal/appearance section with phase, temperature/reference qualifications; at least meaningful reviewed common-element crystal entries and comparison diagrams, with honest reviewed coverage for the rest.
- Bounded local practice record with export/import/reset; no public score backend. Static deploy compatible with project subdirectory.
- Tests of science constraints, question answers/options/coverage, malformed files/state, bounds and no fabricated unknown facts; browser responsive 1440/390/320, quiz completion, compare, keyboard, images and file outputs; CI and live verified separately.
